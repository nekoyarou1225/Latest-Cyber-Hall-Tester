# GLOBAL_CYBER_MAP_SPEC.md
## THUNDERHALL (サンダーホール) — 世界・日本全国リアルタイム3D地球儀 & 2D戦術マップ仕様書

### 1. 概要
Zone 2 (Center Main Stage) において Three.js WebGL 3D地球儀と 2D戦術投影マップをリアルタイム切り替え可能に実装。

### 2. 日本国内13戦略拠点 (`JAPAN_STRATEGIC_NODES`)
北海道（札幌/石狩DC）、宮城（仙台IX）、茨城（つくば研究学園）、千葉（印西ハイパースケールDC）、東京（大手町IXコア）、神奈川（横浜海底ケーブル陸揚局）、愛知（名古屋産業IX）、大阪（堂島コアIX）、京都（学術グリッド）、広島（中国リージョンDC）、香川（四国IX）、福岡（博多アジアゲートウェイ）、沖縄（那覇海底ケーブルハブ）の13拠点を収録。

### 3. 視覚表現
- 攻撃光線（赤/紫）、防御シールド（シアン/エメラルド）、ハニーポット誘導アーク（アンバー）、衛星軌道リンク（ゴールド）を色分け描画。
