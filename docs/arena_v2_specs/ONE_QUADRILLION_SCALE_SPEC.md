# ONE_QUADRILLION_SCALE_SPEC.md
## THUNDERHALL (サンダーホール) — $10^{16}$（1京）スケール集約計算エンジン仕様書

### 1. 概要
Bot数およびパケット数を `1` → `100` → `10,000` → `1,000,000` → `100,000,000` → `10,000,000,000,000,000` ($10^{16}$ / 1京) の6段階でスケール可能とする。

### 2. BigInt 厳密精度とハイブリッド集約
- IEEE 754 倍精度浮動小数点の安全整数上限 (`Number.MAX_SAFE_INTEGER = 9,007,199,254,740,991`) を超える $10^{16}$ 領域では、JavaScript `BigInt` による厳密整数演算と JSON 文字列シリアライズ (`"10000000000000000"`) を採用し、桁落ちを防止する。
- 10,000台以下は個別Botノード生成、10,000台超〜1京スケールはクラスタ統計分布テンソル＋サンプリング代表ノードにより、ブラウザ 60fps とメモリ安全性を両立する。
