# THUNDERHALL TESTER — 追加条項 V2.1 & V2.2 統合実装計画書

承認いただいた事前仕様（通信一覧表・入出力スキーマ・失敗時フォールバック・追加パッケージ `@google/genai`）に基づき、既存の **THUNDERHALL TESTER / AegisLab v3.0 Phase 2B** 基盤を破壊することなく、**追加条項 V2.1（信頼性・視覚安全・地理表現・MK1Ai配信規則・緊急情報・段階化）** および **追加条項 V2.2（Gemini セリフ生成・VOICEVOX ずんだもん音声・OBS不要の内蔵YouTubeライブ配信）** を実装します。

---

## ユーザー承認済み確定事項

1. **Gemini API セリフ生成と一方向検疫ゲート**:
   - サーバーサイド（`server.ts`）のみで `@google/genai` SDK（モデル: `gemini-3.8-flash`、`responseSchema` 指定）を呼び出し、APIキーは `SecretString` で保護して画面・ログ・例外・レポートへの平文露出を完全に遮断します（UI上にAPIキー入力欄は設けず、サーバー環境変数 `process.env.GEMINI_API_KEY` を参照）。
   - 入力は「検証済みイベントの要約JSON（5項目のみ：`event_type`, `severity`, `verification_status`, `metrics`, `technical_term`）」に限定し、送信前に必ず 14 カテゴリの個人情報・機密検査（`RedactionEngine`）を実行します。
   - 出力は未信頼データとして 4 段階検疫（①JSON型・URL/コマンド/コード混入遮断、②数値・状態語の一致検証、③禁止語・不安煽り・実在国帰属の破棄、④40文字以内・専門用語解説の確認）を通過したもののみを採用し、失敗時は即座に事前定義テンプレート台詞へフォールバックします。
2. **VOICEVOX ENGINE バックグラウンド統合**:
   - ローカル専用（`127.0.0.1`、既定ポート `50021`、競合時は `50022`〜`50030` へ自動退避、外部公開禁止）の非表示サブプロセスとして管理し、頻出セリフは事前生成キャッシュから再生します。
   - 画面および配信説明欄コピー用パネルに **`「VOICEVOX:ずんだもん」`** とエンジン・音源・立ち絵の利用規約・ライセンス情報を常時表示します。
   - エンジン未検出・停止時は **別TTSによるずんだもん声色の模倣を一切行わず**、即座に「字幕のみ（`SUBTITLE_ONLY`）」または事前録音キャッシュ再生へ自動切替して配信を継続します。
3. **OBS 不要の内蔵 YouTube ライブ配信パイプライン**:
   - システム内蔵エンコーダーと厳格な 5 段階手動ステートマシン（**①設定 `CONFIGURED` → ②接続確認 `CONNECTION_VERIFIED` → ③プレビュー `PREVIEWING` → ④配信開始 `LIVE_STREAMING` → ⑤配信停止 `STOPPED`**）を実装し、段階スキップや自動配信開始・切断後の自動再配信を禁止します。
   - 配信開始（④）は機密検査 `STREAMABLE` 合格とユーザー確認ダイアログの明示承認の両方を必須とし、既定 30 秒の配信遅延バッファ、常時表示の「緊急ブラックアウト」ボタン（即時黒画面＋無音化）、「配信停止」ボタン、および **Intel N100 向け `720p30` 軽量プリセット（負荷上昇時の自動エフェクト縮退）** を備えます。
   - 配信エンコーダーの停止・障害が Tester Core のセキュリティ検査処理を止めない独立分離アーキテクチャとします。

## 1. 段階化ロードマップ（V2.1 条項 F 準拠：S1 〜 S4）

### Stage S1：配信画面・3D地球儀・基本安全制御
- **3D 地球儀 & 管制センター UI**:
  - 上部システムステータスバー、中央大型 3D 地球儀（`Three.js` による大陸・大気発光・通信アーク・到着波紋）、右側情報サイドバーの 3 領域基本構成。
  - **架空リージョン表現（条項 C）**: 既定では実在国名を使用せず、`Region A-01`、`Relay-02`、`Sector C-04` 等の架空リージョン名を表示。設定で明示的に有効化した場合のみ地理参照を表示し、攻撃元の国を断定する表現は一切使用しない。
- **視覚安全・低刺激モード（条項 B）**:
  - すべての演出で **1秒あたり3回（3Hz）を超える点滅** および **画面の大部分（20%超）を占める高速な赤↔白切替** をハードウェア/シェーダー層で禁止。
  - 配信冒頭バナーおよび上部バーで **「低刺激モード（フラッシュ・揺れ・大音量を抑制）」** を既定で選択可能にする。
- **検証対象（MK1Ai-main）向け配信保護規則（条項 D）**:
  - 未修正の脆弱性・回避条件・検査入力の詳細は配信画面に出さず（`REDACTED_UNPATCHED_VULN_DETAIL`）、修正・検証完了までは **課題ID** と **状態（`未着手` / `修正中` / `検証済み`）** のみ表示。
  - 未完成・未検証部分は `NOT TESTED` / `FAIL` / `INCONCLUSIVE` をそのまま表示し、`PASS` を装う演出を禁止。
- **内蔵配信コンソール（V2.2 条項 C）**:
  - 5段階ステートマシン（①設定 → ②接続確認 → ③プレビュー → ④配信開始 → ⑤配信停止）、既定30秒遅延リングバッファ、緊急ブラックアウト、Intel N100 `720p30` 自動縮退プロファイル。

### Stage S2：ずんだもん（Gemini API セリフ生成 + VOICEVOX バックグラウンド統合）
- **Gemini API サーバーサイド統合（V2.2 条項 A）**:
  - `server.ts` にて `@google/genai` の `gemini-3.8-flash` を呼び出し、構造化出力（`speech`, `expression_id`, `costume_id`）を取得。
  - 起動時・設定画面に利用プラン区分（無料枠 / 有料枠）を表示し、無料枠では Google による学習利用の可能性に関する注意喚起を表示するとともに、送信前に個人情報・機密が含まれないことを毎回強制検査。
  - トークンバケット方式のレート制限（最小10秒間隔）とイベント要約 SHA-256 ハッシュによるセリフキャッシュを実装。
- **VOICEVOX ENGINE ローカル管理と立ち絵・字幕連動（V2.2 条項 B）**:
  - `127.0.0.1:50021`（競合時 `50022`〜`50030`）で動作するローカルエンジン監督クラス、頻出台詞の事前生成キャッシュ、`「VOICEVOX:ずんだもん」` クレジット常時表示、エンジン停止時の即時字幕フォールバック（`SUBTITLE_ONLY`）。

### Stage S3：検証連動 20 演出・エンタメ隔離・3D ガラポン抽選
- **検証済み連動 20 演出**:
  - 節目演出は `VERIFIED`（検証済み）の結果にのみ連動。
  - **信頼性隔離（条項 A）**: フェイク演出（`EFFECT-49`〜`52`）は「エンタメモード」限定とし、「研究者モード」では完全無効化。フェイク演出の実行中は消去不能な最前面レイヤーに **`【演出 / SIMULATION】`** を固定表示。架空のミサイル・ICBM・弾道ミサイル表現は一切実装しない。
- **3D ガラポン抽選機**:
  - 六角木製ドラム回転と玉排出の物理演算を `Three.js` で描画し、抽選結果に応じたずんだもん実況セリフと安全演出を再生。

### Stage S4：緊急情報レイヤー（気象庁公開情報のみ）
- **公式データ源限定（条項 E）**:
  - 気象庁（JMA）の公開情報フィード（地震・気象警報）のみを実装対象とし、J-Alert・国民保護情報は実装せず「J-Alert」等の誤認呼称も一切使用しない。
  - 画面上部に **`「この配信は公式情報源ではありません。公式情報を確認してください」`** を常時表示。

## 4. 受け入れ基準（V2.2 条項 D）の自動検証計画

`/テストツール/tests/run_verification.py` にて以下の 6 項目を自動テストし、UI 上でもリアルタイムに検証結果を監査できるようにします：
1. **不正出力破棄テスト**: コマンド・URL・HTMLタグ・数値不一致・状態語矛盾（FAILなのに「安全なのだ」等）・実在国攻撃断定・ミサイル表現を含む Gemini 模擬出力が 100% 破棄され、テンプレート台詞へ切り替わること。
2. **機密非露出テスト**: Gemini API キーおよび YouTube ストリームキー（`SecretString`）が、画面表示・標準出力ログ・例外メッセージ・JSONレポートのいずれにも平文で一切出現しないこと。
3. **Gemini 失敗時継続テスト**: タイムアウト・HTTP 429・APIエラー発生時に、配信および Tester Core が停止せず、即座にテンプレート台詞で継続すること。
4. **VOICEVOX 停止時フォールバックテスト**: VOICEVOX ENGINE 未起動・停止時に、別TTSでの声色模倣を行わず、自動で字幕のみ（`SUBTITLE_ONLY`）または事前キャッシュ再生へ切り替わること。
5. **内蔵配信5段階フロー・独立性テスト**: 「①設定→②接続確認→③プレビュー→④配信開始（確認承認必須）→⑤配信停止」の順序強制、段階スキップ拒否、30秒遅延、緊急ブラックアウト、および配信停止時に Tester Core が停止しないこと。
6. **Intel N100 `720p30` プロファイル計測テスト**: N100 相当プロファイルにおける FPS・CPU負荷・メモリ使用量の計測と、閾値超過時のエフェクト自動縮退（パーティクル削減→3D簡易化→2D軽量表示）が動作すること。
